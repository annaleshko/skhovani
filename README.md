# Сховані

Цифровий музей українського мистецтва, яке сьогодні не побачиш наживо: [shovani.vercel.app](https://shovani.vercel.app) — без встановлення й без логіну.

## Що вміє

Мобільний шлях: місто → карта → переліт → фасад музею → зала → порожня рама / розкриття → тур із лупою → паспорт твору → AI-гід → шпалери. У MVP — 10 творів у 5 музеях. З карти маршруту можна відкрити музей і вільно оглянути рами в залі (`explore`).

## Стек

Next.js 16 (App Router), TypeScript, Tailwind CSS, Framer Motion. AI-гід — OpenAI `gpt-4o-mini` через серверний маршрут `/api/guide`. Деплой на Vercel (корінь проєкту — `web/`).

## Структура репозиторію

- `web/` — застосунок (Next.js);
- `data/` — паспорти творів і база фактів для гіда;
- `docs/` — специфікація, паспорти, база знань гіда, референси з Figma, а також робочі матеріали процесу: промти для Cursor, QA-звіт і скріншоти перевірок;
- `.cursor/` — правила проєкту для Cursor;
- `art/`, `hidden art/`, `wallpapers/`, `museums/`, `backgrounds/`, `map/`, `figma-export/`, `icon/` — дизайн-матеріали.

## Як працює AI-гід

- Відповідає лише з перевірених фактів паспорта твору та додаткових знань (`extendedKnowledge`) із посиланнями.
- У відповіді валідуються `sourceId` — лише дозволені джерела цього твору.
- Guard на числа/дати: модель не може назвати кількість, рік чи розмір, якого немає в корпусі фактів.
- Відповіді про місце твору залежать від статусу (викрадений / в укритті / врятований); адреси сховищ не вигадуються.
- Поза темою або без даних — коротка відмова й пропозиція іншого питання.
- Без ключа API або при збої — кураторські / fallback-відповіді з тієї ж бази фактів.

## Що працює, а що обмеження

**Працює:** повний шлях 1–10 і фінал, зала з світлом і підписами, тур і паспорт, гід із джерелами, шпалери, прогрес і чат у браузері (`localStorage`), вільний огляд залу з карти.

**Обмеження:** без акаунтів — прогрес лише локально на пристрої; контент покриває 10 творів; rate limit гіда — in-memory на інстанс (не спільний між репліками). Біллінг OpenAI (передплачені кредити без автопоповнення) — основний захист від вартості.

## Джерела й права

- Зображення — Wikimedia Commons (public domain / CC BY / CC BY-SA); автори фото вказані у вкладці «Джерела».
- Факти — каталоги музеїв (museum-digital), реєстр war-sanctions.gur.gov.ua, звіти HRW, енциклопедії та українські медіа; додаткові перевірені факти з Google Arts & Culture, Wikipedia, Smithsonian Magazine тощо.
- Кожна відповідь гіда супроводжується посиланням на джерело (`sourceId`).

## Як запустити

```bash
cd web
npm i
```

Створіть `web/.env.local`:

```
OPENAI_API_KEY=…
OPENAI_MODEL=gpt-4o-mini
```

```bash
npm run dev
```

Деплой: Vercel, Root Directory = `web`, ті самі змінні оточення.
